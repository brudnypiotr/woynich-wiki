# woynich-wiki

`woynich-wiki` (codename):  a **project knowledge base with a paper trail**. It collects project sources (documents, Jira, code, transcripts, emails), keeps the originals, and builds a read-only wiki in which every statement links to its exact source.

This repository is the **blueprint**: generic code, templates and instructions with no project data. Clone it, run the setup, and create an instance for one client.

- [docs/PITCH.md](docs/PITCH.md): what it is and why (for managers)
- [docs/DESIGN.md](docs/DESIGN.md): decisions, modules, locators
- [docs/CRITICAL-ANALYSIS.md](docs/CRITICAL-ANALYSIS.md): risks and mitigations
- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): patterns, extensibility, secrets, search, connectors
- [docs/VISION.md](docs/VISION.md): rollout, demo ideas, business model, related work
- [pitch/index.html](pitch/index.html): 8-slide pitch deck (open in a browser; ← → to navigate, N for speaker notes)

Status: design phase.

> `pitch/assets/` contains Example logo and product imagery taken from example.com for the internal pitch only. They are company property and not part of the blueprint.
