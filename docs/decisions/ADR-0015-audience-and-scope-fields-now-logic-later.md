# ADR-0015: Audience and scope fields now, logic later

**Context.** A client-facing edition and shared core knowledge are future steps.

**Decision.** `audience` and `scope` exist in the record schema from day one with defaults; no filtering logic yet.

**Consequences.** No data migration later.
