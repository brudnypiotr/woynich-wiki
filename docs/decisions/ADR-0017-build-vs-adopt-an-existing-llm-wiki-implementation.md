# ADR-0017: Build vs adopt an existing LLM Wiki implementation

**Context.** Open-source LLM Wiki projects exist but are early prototypes.

**Decision.** Default: build on the proven provenance pipeline; review 1–2 projects for licence, Windows support and no-admin operation before M5.

**Consequences.** Decision recorded after the review.
